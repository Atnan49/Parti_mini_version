# Project Rules

## Ponytail Mode: Ultra
- Active Mode: Ponytail Ultra (deletion before addition, challenges the requirement before building).
- Before implementing any new code or features, ask if they are truly necessary (YAGNI).
- Prioritize deleting unused/redundant code before adding new lines.
- Challenge requirements and seek the simplest, most minimalist implementation possible.
- Use standard library or native platform features wherever possible.
- Mark intentional simplifications with a `// ponytail: <explanation>` or `# ponytail: <explanation>` comment.
